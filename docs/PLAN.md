# 포트폴리오 사이트 기획서 (확정본)

> 작성일: 2026-10-29 · 상태: 확정 (이전 초안: 2026-10-28)

## 1. 어떤 사이트인가요

인기 견종 12종의 **성격 정보**를 보여주고, 강아지 사진으로 **견종을 알아보는 AI 기능**을 함께 담은 사이트예요. 방문자는 여기서 나와 잘 맞는 강아지를 찾아보고, 입양을 진지하게 고민해 볼 수 있어요.

이 사이트는 "원하는 품종을 고르는 곳"이 아니에요. **"나와 맞는 강아지를 이해하는 곳"**이에요. 보호소에 있는 강아지는 대부분 믹스견이에요. 그래서 성격은 품종보다 개체마다 차이가 크다는 점을 사이트 곳곳에서 알려주고, 믹스견 입양도 자연스럽게 함께 권해요.

## 2. 누구를 위한 사이트인가요

강아지를 좋아하는 **누구나** 볼 수 있어요. 나이, 강아지 지식, 입양 계획은 상관없어요. 어린이부터 어르신까지 쉽게 볼 수 있어야 해서, 다음 원칙을 지켜요.

- **쉬운 말**: 전문 용어를 쓰지 않아요. 처음 온 사람도 바로 이해할 수 있게 써요.
- **보기 쉬운 화면**: 본문 글씨는 18px 이상이에요. 색 대비는 웹 접근성 기준(WCAG AA)을 지키고, 화면은 사진 중심으로 짜요. 모든 사진에는 대체 텍스트를 달고, 키보드만으로도 쓸 수 있게 만들어요.
- **어떤 기기에서든**: 휴대폰, 태블릿, PC 어디서든 잘 보여요.
- **가입 없이**: 회원가입이나 로그인 없이 모든 기능을 바로 쓸 수 있어요. 이름, 이메일 같은 개인정보는 받지 않아요. 올린 사진은 **방문자의 기기 안에서만 분석하고, 어디에도 보내거나 저장하지 않아요.**

## 3. 견종 정보

### 12종 (확정)

| 소형 (6) | 중형 (4) | 대형 (2) |
|---|---|---|
| 말티즈 | 웰시코기 | 골든 리트리버 |
| 토이 푸들 | 시바견 | 래브라도 리트리버 |
| 포메라니안 | 진돗개 | |
| 시츄 | 비글 | |
| 비숑 프리제 | | |
| 치와와 | | |

여기에 **믹스견 안내 카드**를 하나 더 둬요. 믹스견은 13번째 견종이 아니에요. "보호소 강아지 대부분은 믹스견이고, 성격은 직접 만나봐야 알 수 있다"는 이야기를 전하는 카드예요.

### 성격 지표 4가지

각 견종을 아래 네 가지 기준에 따라 1~5점으로 보여줘요.

1. **아이와 잘 지내요**
2. **다른 동물과 잘 지내요** (강아지, 고양이)
3. **처음 보는 사람에게 친근해요**
4. **훈련이 쉬워요**

점수는 AKC 견종 특성 같은 공개 자료를 참고해서 정해요. 설명은 그대로 옮기지 않고 직접 써요. 참고한 출처는 사이트에 밝혀요. 모든 점수 옆에는 "같은 견종이라도 강아지마다 다를 수 있어요"라는 안내를 함께 둬요.

견종 카드 하나에는 사진, 이름, 한 줄 성격 요약, 성격 지표 4개, 짧은 설명이 들어가요.

## 4. AI 견종 분류

### 어떻게 동작하나요

방문자가 강아지 사진을 올리면, 12종 중 어떤 견종과 닮았는지 알려줘요. 결과 화면에서 해당 견종의 상세 페이지로 바로 이동할 수 있어요.

### 정직하게 답하기

분류기는 어떤 사진을 받든 12종 중 하나를 답하려고 해요. 그래서 이렇게 보완해요.

- 가장 가능성 높은 **후보 3개**를 함께 보여줘요.
- 확신이 낮으면 "잘 모르겠어요. 여러 견종이 섞인 믹스견일 수도 있어요"라고 답하고, 믹스견 안내 카드로 연결해요.
- 강아지 사진이 아닌 것 같으면 다시 올려달라고 안내해요.

### 기술 방식

- **모델**: 이미 학습된 이미지 모델(MobileNet 또는 EfficientNet)을 12종에 맞게 추가로 학습시켜요(전이 학습).
- **실행 위치**: 모델은 **방문자의 브라우저 안에서** 돌아가요(TensorFlow.js 또는 ONNX Runtime Web). 사진이 기기 밖으로 나가지 않아서 "저장하지 않는다"는 약속을 확실히 지킬 수 있어요. 서버도 필요 없어요.
- **학습 데이터**: Stanford Dogs 같은 공개 데이터셋을 기본으로 써요. 다만 진돗개, 시바견, 비숑 프리제는 공개 데이터셋에 없을 수 있어요. 개발 전에 확인하고, 없으면 사진을 따로 모아요. 이때 이용 조건을 꼭 지켜요.
- **학습 환경**: Google Colab에서 학습하고, 완성된 모델 파일만 사이트에 넣어요.

## 5. 방문자가 무엇을 하길 바라나요

**핵심 목표는 "나에게 맞는 강아지를 찾고, 입양을 고민해 보기"예요.** 이 목표를 위해 네 가지 장치를 둬요.

- **성격 필터와 비교**: "아이와 잘 지내는 견종만 보기"처럼 조건으로 걸러 보고, 견종 2~3종을 나란히 비교할 수 있어요.
- **성격 매칭 질문**: "집에 아이가 있나요?", "다른 반려동물이 있나요?" 같은 짧은 질문에 답하면 잘 맞는 견종을 추천해요.
- **링크로 공유하기**: 매칭 결과는 링크 주소에 답변을 담아 공유해요(예: `?kids=1&pets=0`). 서버나 계정이 없어도 가족, 친구에게 결과를 보낼 수 있어요. 관심 견종은 방문자의 브라우저에만 기억해요.
- **입양 전 체크리스트와 입양 정보**: 견종 상세 페이지 마지막에 체크리스트를 둬요. 비용, 시간, 공간, 가족 동의, 15년 가까운 책임 같은 내용이에요. 그 아래에 **국가동물보호정보시스템(animal.go.kr)** 링크와 지역 보호소 안내를 넣어요.

## 6. 사이트 구조

```
홈
├─ 소개: 사이트 목적, 바로가기 (견종 찾기 / 사진으로 알아보기)
├─ 견종 둘러보기: 12종 카드 + 믹스견 카드, 성격 필터, 비교
│   └─ 견종 상세: 성격 지표, 설명, 입양 전 체크리스트, 입양 정보 링크
├─ 나와 맞는 강아지 찾기: 매칭 질문 → 추천 결과 → 공유 링크
├─ 사진으로 견종 알아보기: 업로드 → 후보 3개 → 상세 페이지로 연결
└─ 만든 과정: 데이터, 모델, 정확도, 헷갈린 견종 이야기
```

## 7. 만든 과정 공개

포트폴리오 사이트인 만큼 **만든 과정을 공개해요.** 아래 내용을 쉬운 말로 소개해요.

- 사용한 데이터와 출처, 견종별 사진 수
- 고른 모델과 그 이유, 브라우저에서 실행하는 이유(개인정보 보호)
- 전체 정확도와 견종별 정확도
- **모델이 자주 헷갈린 견종 쌍**: 말티즈, 비숑, 토이 푸들처럼 하얗고 곱슬한 소형견이 대표적이에요. 이 부분이 기술적으로 가장 흥미로운 이야기가 될 거예요.
- 이 기능이 못하는 것: 믹스견 판별, 개체 성격 예측 등

## 8. 디자인 방향

**따뜻하고 친근한 느낌**으로 만들어요. 부드러운 크림색, 따뜻한 주황 계열을 쓰고, 모서리는 둥글게 해요. 사진은 크게 보여주고, 버튼은 크고 문구는 명확하게 써요. 성격 점수는 별점 대신 발바닥 아이콘처럼 귀여운 표현을 써도 좋아요. 다만 숫자도 함께 보여줘서 누구나 정확히 읽을 수 있게 해요.

## 9. 개발과 배포

- **사이트**: Vite + React로 만드는 정적 사이트예요. 견종 정보는 JSON 파일 하나로 관리해요.
- **배포**: GitHub Pages 또는 Vercel. 서버가 없어서 무료로 운영할 수 있어요.
- **저장소**: 지금 있는 `my-portfolio` 저장소를 그대로 써요.
