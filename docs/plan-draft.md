# 포트폴리오 사이트 기획서 (초안)

> 작성일: 2026-10-29
> 상태: 초안. 아래 "정해야 할 것"을 채우면 확정해요.

---

## 1. 한 줄 소개

인기 강아지 12종의 특성을 한눈에 비교해서, **나와 잘 맞는 견종을 찾고 입양을 고민해 볼 수 있게** 돕는 사이트.

---

## 2. 누가 보나요? (대상)

- **강아지를 좋아하는 모든 사람**
- 그중에서도 특히 이런 사람들
  - 강아지를 키워 보고 싶지만 어떤 견종이 맞을지 모르는 사람
  - 입양이나 분양을 실제로 고민하는 사람
  - 그냥 여러 견종을 구경하는 게 즐거운 사람

**그래서 이렇게 만들어요**
- 전문 용어는 줄이고 누구나 쉽게 읽을 수 있게 써요.
- 사진 위주로 따뜻하고 편안한 분위기를 만들어요.
- 휴대폰에서도 보기 편하게 만들어요.

---

## 3. 무엇을 보여주나요? (콘텐츠)

### 3-1. 인기 강아지 12위
- 1위부터 12위까지 순위대로 견종을 카드로 보여줘요.
- 순위의 출처를 꼭 밝혀요. (예: 국내 반려견 등록 통계, 관련 협회 자료 등)

### 3-2. 견종별 정보 (카드 및 상세 페이지)

| 항목 | 예시 |
|---|---|
| 사진 | 대표 사진 1~3장 |
| 크기 | 소형 / 중형 / 대형 |
| 성격 | 활발함, 온순함, 독립적 등 |
| 활동량 | 필요한 산책 시간 (★1~5) |
| 털 빠짐 | 적음 / 보통 / 많음 |
| 아파트 생활 | 적합 / 보통 / 넓은 공간 필요 |
| 초보자 추천 | 예 / 아니오 |
| 짖음 정도 | ★1~5 |
| 평균 수명 | 예: 12~15년 |
| 주의할 건강 문제 | 자주 걸리는 질환 |
| 이런 분께 추천해요 | 예: "산책을 좋아하는 1인 가구" |

---

## 4. 보고 나서 무엇을 하길 바라나요? (목표 행동)

1. **나와 잘 맞는 견종 알아보기** (가장 중요해요)
2. **입양이나 분양을 진지하게 고민해 보기**
3. **마음에 드는 견종을 저장하거나 친구에게 공유하기**

---

## 5. 주요 기능

| 기능 | 설명 | 연결되는 목표 |
|---|---|---|
| 견종 맞춤 테스트 | 질문 5~7개(주거 형태, 산책 시간, 알레르기, 가족 구성 등)에 답하면 잘 맞는 견종 TOP 3을 추천해요 | 목표 1 |
| 조건 필터 | 크기, 활동량, 털 빠짐, 아파트 적합도로 12종을 걸러 봐요 | 목표 1 |
| 견종 비교 | 2~3종을 골라 나란히 비교해요 | 목표 1 |
| 찜하기 ♥ | 마음에 드는 견종을 저장하고 '내 찜 목록'에서 모아 봐요 | 목표 3 |
| 공유하기 | 견종 페이지나 테스트 결과를 링크로 공유해요 (카카오톡, 링크 복사) | 목표 3 |
| 입양 가이드 | 입양 전 체크리스트, 책임감 안내, 유기견 입양 정보 링크를 제공해요 | 목표 2 |

## 6. 사이트 구성 (메뉴)

```
홈
├─ 인기 강아지 12위 (목록 + 필터)
│   └─ 견종 상세 페이지 × 12
├─ 나와 맞는 견종 찾기 (맞춤 테스트 → 결과)
├─ 견종 비교
├─ 내 찜 목록
└─ 입양 가이드
```

### 홈 화면 흐름
1. 첫 화면: "나와 꼭 맞는 강아지를 찾아보세요" + **[테스트 시작]** 버튼
2. 인기 강아지 12위 미리보기 (카드 슬라이드)
3. 입양 전에 꼭 생각해 볼 것 (짧은 안내 + 입양 가이드 링크)

## 7. 분위기와 디자인

- **톤**: 따뜻하고 다정하게, 친근한 말투로 써요 ("~해요")
- **색감**: 크림색, 연한 갈색 같은 부드러운 파스텔 톤
- **이미지**: 강아지 사진이 주인공이에요. 저작권 확인된 사진만 써요.
- **반응형**: 휴대폰, 태블릿, PC 모두 지원해요. **휴대폰 화면부터** 설계해요.

### 7-1. 색상

| 역할 | 색상 코드 | 쓰는 곳 |
|---|---|---|
| 배경 | `#FFF8EE` 크림 | 페이지 바탕 |
| 카드 배경 | `#FFFFFF` 흰색 | 견종 카드 |
| 메인 버튼 | `#8B5A3C` 갈색 | [테스트 시작] 등 주요 버튼 (흰 글씨) |
| 강조 | `#C68B59` 연갈색 | 순위 배지, 별점, 장식 |
| 글자 | `#3E2C23` 진한 갈색 | 본문, 제목 |
| 포인트 | `#F2A7A7` 연분홍 | 찜 ♥ |

- 글자는 항상 진한 색으로 써요. 파스텔 위에 파스텔 글씨는 쓰지 않아요.
- 연갈색(`#C68B59`)에 흰 글씨를 올리면 잘 안 읽혀서, 버튼은 한 단계 진한 갈색(`#8B5A3C`)을 써요.

### 7-2. 글꼴

- **Pretendard** 한 가지만 써요. (대안: 나눔스퀘어라운드)
- 굵기와 크기로 위계를 나눠요.

| 용도 | 크기 (휴대폰) | 굵기 |
|---|---|---|
| 큰 제목 | 24px | 굵게 (700) |
| 소제목 | 18px | 중간 (600) |
| 본문 | 16px | 보통 (400) |
| 보조 설명 | 14px | 보통 (400) |

### 7-3. 반복되는 부품 (컴포넌트)

| 부품 | 구성 | 모양 |
|---|---|---|
| 견종 카드 | 사진, 순위 배지, 이름, 크기 태그, ♥ 버튼 | 모서리 16px, 옅은 그림자 |
| 별점 | ★1~5 (활동량, 짖음 정도) | 강조색으로 채우고, 빈 별은 연한 회색 |
| 태그 | "초보자 추천", "아파트 적합" 등 | 알약 모양 (모서리 999px) |
| 큰 버튼 | [테스트 시작] | 메인 버튼색, 알약 모양, 가로 꽉 차게 |
| 작은 버튼 | 공유, 비교 담기 | 테두리만 있는 알약 모양 |

### 7-5. 사진 가이드

- 비율을 통일해요: 카드 **4:3**, 상세 페이지 **16:9**
- 밝은 배경, 자연광 사진 위주로 골라요.
- 사진마다 **출처와 라이선스**를 기록해 둬요. (9번 "사진 구하기"와 연결)

## 8. 성공 기준 (이렇게 되면 잘된 거예요)

- 방문자가 맞춤 테스트를 끝까지 해 봐요.
- 견종 상세 페이지를 여러 개 둘러봐요.
- 찜하기나 공유하기를 눌러요.
- 입양 가이드 페이지까지 들어가 봐요.
